# Self-review checklist

## Format

+ [ ] Check if file/folder, variable, function, class are correct format and meaningful?
+ [ ] Check if added Code/Comment/Import/Using are duplicate?
+ [ ] Check if all complex paragraph codes are commented and the content of that comments are clear and unambiguous?

## Third Party

+ [ ] Check if the library is supported with the current OS?
+ [ ] Check if the library's functions are duplicate with other used libraries?
+ [ ] Check if the library's version is specified?
+ [ ] Check if the library's license type is non-copyleft license and does not require source code disclosure?

## Source Code
+ [ ] Check if common widgets are moved to \widgets folder?
+ [ ] Check if size, padding, margin, color are hard-coded?
+ [ ] Check if use text style of AppTextStyle for Text widget?
+ [ ] Check if all messages are added to \translation\xxx.json?
+ [ ] Check if the image's format is .png and is exported with 4x mode from design. Check if the icon's format is .svg?
+ [ ] Check if add functions are over long? It should be divided according to responsibilities. (No more than 100 lines).
+ [ ] Check if the code structure is indented according to the structure?
+ [ ] Check if redundant and unused codes are removed?
+ [ ] Check if all warnings and errors of Lint are resolved?
+ [ ] Check if all [ZWSP](Zero-width-space) are removed?
+ [ ] Check if all routing navigation  must be placed in an async function?
